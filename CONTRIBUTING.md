# Contributing

Thank you for contributing to `@illusions-lab/milkdown-plugin-mdi`.

Before opening a pull request:

1. Search existing issues and pull requests.
2. For syntax changes, document the grammar and round-trip behavior.
3. Add or update focused tests.
4. Run `npm test` and `npm run typecheck`.

Keep pull requests focused and explain compatibility implications. Changes to the MDI grammar should include source text, editor behavior, and serialized output.

By contributing, you agree that your contribution is provided under the MIT License.
